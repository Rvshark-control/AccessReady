# ♿ AccessReady — Frontend UI & Accessibility Engine

> **Frontend client application for AccessReady — built with React, Vite, and modern Web Accessibility (WCAG) standards.**

This branch (`claude-frontend-ui`) houses the client-side architecture, interactive patient profile setup, facility search interfaces, barrier detection UI, and dynamic checklist generation engine for **AccessReady**.

---

## 🎨 Key Frontend Features

* 📋 **Accessibility Requirement Builder:** Multi-step intake form allowing patients to specify mobility, sensory, cognitive, and physical accommodation needs.
* 🏥 **Interactive Facility Matcher:** Visual search results featuring high-contrast indicator badges (Verified, Warning, Unverified).
* ⚠️ **Real-Time Barrier Alerts:** Visual risk notifications highlighting missing or incomplete facility resources before appointment booking.
* 📑 **Dynamic Preparation Checklist UI:** Printable and exportable patient accommodation checklists customized per facility visit.
* ♿ **WCAG Compliant Interface:** High-contrast color palettes, screen-reader friendly DOM structure, keyboard-navigable components, and responsive layout across desktop and mobile devices.

---

## 🛠️ Frontend Tech Stack

* **Framework:** React / Next.js
* **Build Tool:** Vite
* **Styling:** Tailwind CSS / Custom Accessible UI Components
* **State Management:** React Context / Hooks
* **Icons & Assets:** Lucide React / Accessible SVG Suites
